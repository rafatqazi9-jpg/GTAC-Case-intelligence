    Structured fields
    Recovered from the same case text

    Want to run it on your own case text? python -m src.server --open serves an interactive version that calls the same extractor live. It binds to 127.0.0.1 only and stores nothing — which is exactly why this hosted page cannot do it: pasting case text into a page served from the internet would send it off your machine. What you see above is recorded output, exported by tools/export_demo.py. The regexes are deliberately not reimplemented in this page either — two copies of a parser drift, and the page would start showing results the tool would not produce.
